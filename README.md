# QUBIXS Website

A frontend-first Next.js website prototype for QUBIXS, a technology brand focused on software products, security services and custom development.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4 (global CSS design system)
- Framer Motion
- Lucide React

## Getting started

```bash
yarn install
yarn dev
```

Open http://localhost:3000.

## Available routes

- `/`
- `/products`
- `/products/qubixs-dine`
- `/products/qubixs-commerce`
- `/products/qubixs-stock`
- `/products/qubixs-flow`
- `/services/security`
- `/services/development`
- `/about`
- `/contact`

## Notes

- Product entries are sample previews, not claims of released products.
- The contact form is frontend-only and does not send or store submissions.
- Payments, authentication, backend APIs, customer accounts and admin functionality are intentionally not implemented.
- Replace the example metadata URL in `src/app/layout.tsx` with the production domain before launch.
